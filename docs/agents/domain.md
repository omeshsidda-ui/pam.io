# Domain docs

pam.io uses a single domain context for the browser game.

- Read the root `GLOSSARY.md` when it exists. Use its terms in specs, issues, code names, and test descriptions.
- Read relevant decisions in `docs/adr/` when they exist. If a proposal conflicts with an ADR, identify the decision and explain what would justify revisiting it.
- Add glossary entries and ADRs as gameplay terms or significant design decisions are settled. The README describes the game and links to the existing gameplay docs.
