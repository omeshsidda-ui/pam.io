# Contributing to pam.io

Small fixes, new ideas, and gameplay feedback are welcome.

## Report a problem

Describe what you did, what happened, and what you expected. Include your browser and device. For a mobile issue, mention orientation and steering mode. A short clip helps explain close collisions or unexpected movement. [Open an issue](https://github.com/omeshsidda-ui/pam.io/issues)

## Send a change

1. Fork the repo, create a branch, and follow the [local setup](README.md#run-locally).
2. Make one focused change. Run `npm run build` and try the affected part of the game.
3. Open a pull request describing what changed and how you checked it. For a visual change, include a screenshot if you can.

Original code contributions are accepted under the project’s [MIT License](LICENSE). If you add third-party assets, identify their source and license in [third-party notices](THIRD_PARTY_NOTICES.md).
